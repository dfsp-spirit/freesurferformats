# Merge two bounding boxes.

Merge two bounding boxes.

## Usage

``` r
# S3 method for class 'bbox'
merge(bbox1, bbox2)
```

## Arguments

- bbox1:

  numeric vector of length 6 or NULL.

- bbox2:

  numeric vector of length 6 or NULL.

## Value

numeric vector of length 6, the union of the two boxes.
