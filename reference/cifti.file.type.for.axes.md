# Get the standard CIFTI-2 file type for a set of axes.

Look up the file type that the format defines for the combination of
matrix index types of the axes, see
[`cifti.file.types`](https://dfsp-spirit.github.io/freesurferformats/reference/cifti.file.types.md).

## Usage

``` r
cifti.file.type.for.axes(axes)
```

## Arguments

- axes:

  list of axes, see
  [`cifti.header.from.axes`](https://dfsp-spirit.github.io/freesurferformats/reference/cifti.header.from.axes.md).

## Value

a one row data.frame, see
[`cifti.file.types`](https://dfsp-spirit.github.io/freesurferformats/reference/cifti.file.types.md),
or a row with `intent_code = 3000` ('ConnUnknown') and empty file name
extension for a combination that the standard does not define.

## Examples

``` r
axis_brain <- cifti.axis.brain.models(list(cifti.brain.model.surface("lh", 10L)))
type <- cifti.file.type.for.axes(list(cifti.axis.scalars("m"), axis_brain))
type$extension
#> [1] ".dscalar.nii"
```
