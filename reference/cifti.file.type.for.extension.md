# The CIFTI-2 file type a file name names.

The CIFTI-2 file type a file name names.

## Usage

``` r
cifti.file.type.for.extension(filepath)
```

## Arguments

- filepath:

  character string, a file name.

## Value

character string, the standard file name extension the name ends with
(e.g. '.pscalar.nii'), or the empty string if it does not end with one
of them.
