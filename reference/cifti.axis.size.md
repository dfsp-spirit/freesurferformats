# The number of matrix entries an axis covers.

The number of matrix entries an axis covers.

## Usage

``` r
cifti.axis.size(axis)
```

## Arguments

- axis:

  an axis, see
  [`cifti.header.from.axes`](https://dfsp-spirit.github.io/freesurferformats/reference/cifti.header.from.axes.md).

## Value

integer, the size of that matrix dimension.
