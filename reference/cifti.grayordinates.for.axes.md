# Build the brainordinate table of an axis.

Build the brainordinate table of an axis.

## Usage

``` r
cifti.grayordinates.for.axes(axis)
```

## Arguments

- axis:

  an axis of type 'CIFTI_INDEX_TYPE_BRAIN_MODELS'.

## Value

a data.frame, see
[`cifti.grayordinates`](https://dfsp-spirit.github.io/freesurferformats/reference/cifti.grayordinates.md).
