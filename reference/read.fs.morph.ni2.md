# Read morphometry data from FreeSurfer NIFTI v2 format files.

Read morphometry data from FreeSurfer NIFTI v2 format files.

## Usage

``` r
read.fs.morph.ni2(filepath)
```

## Arguments

- filepath:

  path to a file in FreeSurfer NIFTI v2 format, potentially with the
  FreeSurfer hack. See
  [`read.nifti2.data`](https://dfsp-spirit.github.io/freesurferformats/reference/read.nifti2.data.md)
  for details.

## Value

numeric vector, the morphometry data
