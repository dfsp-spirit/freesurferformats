# Accept the input forms of a CIFTI-2 header.

Accept the input forms of a CIFTI-2 header.

## Usage

``` r
cifti.header.of(x)
```

## Arguments

- x:

  character string (a file path), an `fs.cifti` or an `fs.cifti.data`
  object.

## Value

an `fs.cifti` object, see
[`read.cifti.header`](https://dfsp-spirit.github.io/freesurferformats/reference/read.cifti.header.md).
