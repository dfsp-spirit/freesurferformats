# Compute vox2vox matrix between two volumes.

Compute vox2vox matrix between two volumes.

## Usage

``` r
mghheader.vox2vox(header_from, header_to)
```

## Arguments

- header_from:

  the MGH header of the source volume

- header_to:

  the MGH header of the target volume

## Value

4x4 numerical matrix, the transformation matrix
