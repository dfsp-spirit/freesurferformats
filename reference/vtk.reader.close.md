# Close the connection of a VTK legacy reader.

Close the connection of a VTK legacy reader.

## Usage

``` r
vtk.reader.close(reader)
```

## Arguments

- reader:

  an environment as returned by
  [`vtk.reader.new`](https://dfsp-spirit.github.io/freesurferformats/reference/vtk.reader.new.md).

## Value

`NULL`, invisibly.
