# Get the parcels axis of a template file.

Get the parcels axis of a template file.

## Usage

``` r
cifti.parcels.axis.of(template_cii)
```

## Arguments

- template_cii:

  an `fs.cifti` object, see
  [`cifti.header.of`](https://dfsp-spirit.github.io/freesurferformats/reference/cifti.header.of.md).

## Value

the parcels axis of the file, see
[`cifti.axis.parcels`](https://dfsp-spirit.github.io/freesurferformats/reference/cifti.axis.parcels.md).
