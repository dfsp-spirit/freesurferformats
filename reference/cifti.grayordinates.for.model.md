# Expand one brain model entry into a brainordinate table.

Expand one brain model entry into a brainordinate table.

## Usage

``` r
cifti.grayordinates.for.model(map, model)
```

## Arguments

- map:

  the indices map the brain model belongs to, see
  [`cifti.map.for.dim`](https://dfsp-spirit.github.io/freesurferformats/reference/cifti.map.for.dim.md).

- model:

  one brain model entry of the map.

## Value

a data.frame, see
[`cifti.grayordinates`](https://dfsp-spirit.github.io/freesurferformats/reference/cifti.grayordinates.md).
