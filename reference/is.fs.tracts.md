# Check whether an object is an fs.tracts instance.

Check whether an object is an fs.tracts instance.

## Usage

``` r
is.fs.tracts(x)
```

## Arguments

- x:

  any R object.

## Value

logical, TRUE if `x` is an `fs.tracts` instance.

## Examples

``` r
is.fs.tracts("not tracts");
#> [1] FALSE
```
