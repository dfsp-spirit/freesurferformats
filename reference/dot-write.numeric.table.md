# Write a numeric table to a text file, one matrix row per line.

Write a numeric table to a text file, one matrix row per line.

## Usage

``` r
.write.numeric.table(filepath, m)
```

## Arguments

- filepath:

  character string, path to the output file. Files ending in `.gz` are
  gzip-compressed.

- m:

  numeric matrix, the table to write.

## Value

NULL, invisibly.
