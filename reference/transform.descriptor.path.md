# Get the file path recorded in a volume descriptor.

Get the file path recorded in a volume descriptor.

## Usage

``` r
# S3 method for class 'descriptor.path'
transform(descriptor)
```

## Arguments

- descriptor:

  `NULL` or a volume descriptor, see
  [`volume.descriptor`](https://dfsp-spirit.github.io/freesurferformats/reference/volume.descriptor.md).

## Value

`NULL` or character string.
