# Check a list of axes and name the dimensions.

Check a list of axes and name the dimensions.

## Usage

``` r
cifti.check.axes(axes)
```

## Arguments

- axes:

  list of axes, see
  [`cifti.header.from.axes`](https://dfsp-spirit.github.io/freesurferformats/reference/cifti.header.from.axes.md).

## Value

the list, with the axes named by their matrix dimension.
