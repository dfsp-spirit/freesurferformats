# Print an fs.transform instance.

Print an fs.transform instance.

## Usage

``` r
# S3 method for class 'fs.transform'
print(x, ...)
```

## Arguments

- x:

  an `fs.transform` instance.

- ...:

  ignored, only present for consistency with the generic.

## Value

the transform `x`, invisibly.
