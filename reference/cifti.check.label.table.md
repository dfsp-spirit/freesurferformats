# Check a label table for writing.

Check a label table for writing.

## Usage

``` r
cifti.check.label.table(label_table, map_idx)
```

## Arguments

- label_table:

  a data.frame, see
  [`cifti.axis.labels`](https://dfsp-spirit.github.io/freesurferformats/reference/cifti.axis.labels.md),
  or `NULL`.

- map_idx:

  integer, the number of the map, used in the error message.

## Value

the label table, or `NULL`.
