# Check and prepare the data for a set of axes.

Check and prepare the data for a set of axes.

## Usage

``` r
cifti.check.data.for.axes(data, axes)
```

## Arguments

- data:

  the data, see
  [`write.cifti`](https://dfsp-spirit.github.io/freesurferformats/reference/write.cifti.md).

- axes:

  list of axes, see
  [`cifti.header.from.axes`](https://dfsp-spirit.github.io/freesurferformats/reference/cifti.header.from.axes.md).

## Value

the data as an array with the dimensions of the axes.
