# Check a vector of 0-based indices.

Check a vector of 0-based indices.

## Usage

``` r
cifti.check.index.list(indices, what, max_index = NULL)
```

## Arguments

- indices:

  integer vector, the indices.

- what:

  character string, a description of the indices, used in error
  messages.

- max_index:

  integer or `NULL`, the largest allowed index.

## Value

the indices as an integer vector.
