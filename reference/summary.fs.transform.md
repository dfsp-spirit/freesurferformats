# Summarize an fs.transform instance.

Compute the properties of a transformation in a machine-readable form,
for printing or for further processing.

## Usage

``` r
# S3 method for class 'fs.transform'
summary(object, ...)
```

## Arguments

- object:

  an `fs.transform` instance.

- ...:

  ignored, only present for consistency with the generic.

## Value

named list with the entries 'format', 'source', 'space_in', 'space_out',
'voxel_base', 'src', 'dst' (the corresponding fields of the transform),
'translation' (numerical vector of length 3, the last column of the
matrix), 'determinant', 'is_affine' (logical, whether the last row of
the matrix is '0 0 0 1') and 'is_invertible' (logical).

## Examples

``` r
tf <- read.fs.transform(system.file("extdata", "register.dat",
  package = "freesurferformats", mustWork = TRUE
))
summary(tf)$space_out
#> [1] "ras"
```
