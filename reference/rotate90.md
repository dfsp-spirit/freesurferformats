# Rotate 2D matrix clockwise in 90 degree steps.

Rotate 2D matrix clockwise in 90 degree steps.

## Usage

``` r
rotate90(mtx, times = 1L, clockwise = TRUE)
```

## Arguments

- mtx:

  a 2D matrix

- times:

  integer, how often to rotate in 90 degree steps. Example: pass `3L` to
  rotate `270` degrees.

- clockwise:

  logical, whether to rotate clockwise.
