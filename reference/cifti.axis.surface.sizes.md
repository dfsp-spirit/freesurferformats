# Get the surface sizes of an axis as a named vector.

Get the surface sizes of an axis as a named vector.

## Usage

``` r
cifti.axis.surface.sizes(axis)
```

## Arguments

- axis:

  an axis of type 'CIFTI_INDEX_TYPE_BRAIN_MODELS'.

## Value

named integer vector or `NULL`, the number of vertices per structure,
see
[`cifti.axis.brain.models`](https://dfsp-spirit.github.io/freesurferformats/reference/cifti.axis.brain.models.md).
